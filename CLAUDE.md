# Seedance Shorts Studio

Web UI lokal (Python stdlib saja, tanpa dependensi) untuk membuat klip YouTube Shorts lewat ComfyUI + node API Seedance (ByteDance). Seedance berjalan di cloud lewat API node ComfyUI (butuh login akun Comfy + kredit), bukan di GPU lokal.

## File
- `app.py` — server HTTP (port 7860, hanya 127.0.0.1). UI di `ui.html` (dibaca tiap request, `Cache-Control: no-store`). Proteksi: Host harus 127.0.0.1/localhost (anti DNS-rebinding) dan setiap POST wajib header `X-Studio: 1` (anti CSRF; tanpa ini situs lain bisa memicu generate berbayar/hapus file/ganti `comfy_cmd`). Job ComfyUI masuk antrean `WORK` dan dikerjakan **satu per satu** oleh thread `worker` (timeout dihitung saat job mulai). `GET /api/busy` dipakai supervisor sebelum update. `comfy_url()` di-cache 3 dtk (satu thread mengecek, lainnya memakai hasil terakhir); URL yang pernah menjawab tetap dianggap hidup selama port-nya terbuka (ComfyUI sibuk = `/system_stats` lambat); scan PowerShell `running_comfy` maks tiap 120 dtk; `node_spec` juga menyimpan hasil "node tidak ada" 60 dtk. `/api/status` membaca ujung log saja (`log_tail`), `has_tool` (which, cache 60 dtk), dan menyertakan `dl` (progres unduh model). **VRAM 8 GB**: `free_ollama()` (`/api/ps` + `keep_alive:0`) sebelum job workflow lokal; sebelum LLM, ComfyUI `/free` hanya bila `vram_free` < 6.5 GB. Upload: `POST /api/upload?name=` (body mentah). Render: `POST /api/render` → `render.py` di thread, status lewat `JOBS`.
- **Progres (persen) semua proses**: job ComfyUI → `comfy_ws.py` (klien websocket stdlib ke `/ws?clientId=<job id>`, dibuka sebelum `/prompt`; event executing/progress/progress_state/execution_cached → persen berbobot: sampler & node API 20, loader 2, decode/save 1.5) di `job.progress {pct, stage, step}`, `job.started`/`elapsed`; antre lokal → "Antre ke-N" (dihitung di `GET /api/jobs`), antre di ComfyUI (dipakai aplikasi lain) → cek `/queue`. Render → ffmpeg `-progress pipe:1` (`out_time_us`/durasi). LLM → `/api/chat` streaming, `llm.PROG` (token / `est` per tugas, maks 95%), `GET /api/llm/progress`. Unduh model → `DL.index/count/overall`. Upload → XHR `upload.onprogress`. **Polling ringan**: `poll()` = `POST /api/jobs/query {ids}` (job yang ditunggu proyek ini, `waitIds()`, + job aktif; dulu `GET /api/jobs` 212 KB berisi semua riwayat tiap 2.5 dtk), dijadwalkan ulang sendiri (`pollSoon`): 2 dtk bila ada yang ditunggu/aktif, 6 dtk bila diam; `api()` memanggil `pollSoon` setelah `/api/generate`/`/api/render`; hasil diabaikan bila proyek berganti selama request. UI: `progHTML()` (persen + bar + waktu + sisa ~), `jobState()` membuat `<span class="js" data-job>` yang diperbarui di tempat (`updateJobSpans`, tanpa render ulang daftar video), chip `#act` di nav merangkum proses aktif. Job dianggap "hilang" hanya bila dibuat >2 dtk sebelum `poll()` mulai (`o.t`, `edit.mt/rt`) — dulu job yang dibuat bersamaan dengan poll salah ditandai hilang.
- `remote.py` — akses dari HP/laptop lain lewat **Tailscale**. `remote.kind(ip)`: 127.0.0.1/::1 = local (tanpa login); IP di `remote_nets` (default 100.64.0.0/10 + fd7a:115c:a1e0::/48) = remote, hanya bila `remote_access`; selain itu ditolak (Wi-Fi/internet). `host_ok`: Host remote harus IP literal, nama tanpa titik (MagicDNS) atau `*.ts.net`. PIN PBKDF2 (`remote_pin_salt/hash`), sesi = cookie HMAC dari `remote_secret` (HttpOnly, SameSite=Strict, 30 hari; ganti PIN = semua sesi batal), 5x salah = kunci 5 menit per IP. App bind `0.0.0.0` hanya bila `remote_access` + PIN ada (`BIND`); `POST /api/remote` (hanya dari PC) mengubahnya lalu `os._exit(3)` agar supervisor menyalakan ulang. `GET /api/remote` memberi info Tailscale (`tailscale status --json`) + URL. Halaman login `LOGIN_HTML` di app.py; `/api/login`, `/api/logout`. CLI: `python remote.py --set-pin X --enable`. `izinkan-akses-hp.bat/.ps1`: aturan firewall masuk khusus 100.64.0.0/10 di `app_port` + hapus aturan BLOKIR untuk python aplikasi (dibuat Windows bila prompt firewall dulu di-Cancel). Installer menawarkan Tailscale (winget) + PIN + firewall.
- `ui.html` — UI satu halaman, alur **linear** 5 tahap: 1 Ide → 2 Script → 3 Breakdown → 4 Production → 5 Editing & Sound. Tombol "Lanjut" di tiap tahap menjalankan pekerjaan tahap berikutnya bila belum ada (storyline → script → breakdown). Pengaturan (ComfyUI, model workflow, Ollama, akses dari HP, API key, versi/update) di panel ⚙. Responsif: di bawah 820px satu kolom, nav dua baris (tahap; proyek + ⚙), input 16px (iOS tidak zoom). `api()` memuat ulang halaman bila 401 (sesi HP habis → halaman login). Semua data di `projects/<nama>.json` (v2): `dev, story, target, maxScene, scenes[] (duration, location, time, action, dialog, onscreen_text, visual, chars[], loc, props[], shot, cam, sketch{job,img}, prompt (override), takes[{job,file}], take, use, tin, tout, sub), look{style,camera,lighting,palette}, chars[{name,look,wardrobe,makeup,job,img}], locs[], props[], bd, imgwf, prod{engine,model,aspect,resolution,audio}, edit{tr,fade,ca,cv,sub,music,audios,mv,mwf,mp,mjob,rjob,final}`. `migrate()` mengubah proyek lama (panels/style). Kotak model (`MBOX`/`tabModels`) tampil langsung di tahap yang memakai workflow lokal (3 gambar `b-models`, 4 video `v-models`, 5 musik `e-models`); `needModels()` mengecek sebelum mengantre job (tidak ada lagi deretan kartu "Gagal: model belum ada"), progres unduhan disegarkan lewat `status()` selama `DLON`. Job dihubungkan ke item lewat id (sisi klien, `poll()`); prompt video = `compose()` (style + shot/kamera + visual + karakter (fisik, wardrobe, make-up) + lokasi + properti + lighting/palet, "no on-screen text" karena subtitle ditambahkan di Editing).
- **Tombol adaptif** (ui.html): `syncButtons()` (dipanggil di `renderTab`, `navDone`/`save`, `poll`, `status`, `llmStatus`) mengatur disabled + label + `title` alasan + petunjuk `n1..n4` di bar bawah untuk semua tombol utama berdasarkan prasyarat (prompt/ide/storyline/scene/take, `llmReady()`, `comfyReady()`, API key Seedance, ffmpeg, workflow). Tombol per item (gambar referensi, sketsa, ▶ gaya, take) dihitung saat render dengan `pend(o,fk)`; `status()` merender ulang tab saat `comfy`/`has_key` berubah (dulu tombol item tetap terkunci "ComfyUI belum tersambung"). Anti klik ganda: `busyRun(btn,…)` untuk loop "… semua" dan `once(key,…)` per item (`genImg`/`genTake`/`stPreview` membungkus versi `_`), `llmRun` memakai `btn.dataset.busy`. Tata letak: `.body > .inner` bergulir, `.next` footer tetap (tidak menimpa isi); di HP `.next` sticky + `scroll-padding-bottom`, tombol ≥36px. **Anti berat**: `status()` (4 dtk) tidak lagi memanggil `/api/models` (pakai `s.dl`) dan memanggil `loadCfg()` hanya saat ComfyUI baru tersambung & `!cfg.live` (dulu tiap 4 dtk bila node Seedance tidak ada → `renderTab` → semua `<video>` dimuat ulang, 158 request/menit); `loadCfg` merender hanya bila isi config berubah (`CFGSIG`); `stRender` hanya bila isinya berubah (`STSIG`); SVG gaya (filter feTurbulence berat) dibuang setelah foto Pexels termuat. Thumbnail take/klip = `vthumb()` → `GET /api/thumb?f=` (ffmpeg frame 0.5 dtk, lebar 360, `cache/thumbs/<file>.jpg`, maks 2 ffmpeg bersamaan; gagal/ffmpeg tidak ada → 404 → `vtFail` kembali ke `<video>`). `/outputs/` diberi `Cache-Control` (nama file selalu unik). Jangan menaruh kode setelah komentar `//` di baris yang sama (dulu `if(VER0===null)…` tertelan komentar → banner "sudah diperbarui" tampil terus). Audit: skrip Playwright 7 ukuran layar (tertutup/terpotong/keluar layar/target sentuh) + skenario status (layanan mati, proyek kosong/penuh, klik ganda).
- `styles.js` — 13 gaya visual (`STYLES`: id, name, desc, prompt English, lighting, palette) + `styleSVG(st)`: thumbnail ilustrasi SVG buatan tangan (adegan sama per gaya; id SVG diberi awalan `st<id>` agar unik dalam satu halaman). Disajikan app sebagai `/styles.js`. Di tahap 3: klik kartu → `look.styleId` + `look.style` (+ lighting/palet bawaan gaya); breakdown LLM tidak menimpa `style` bila `styleId` terisi. ▶ = pratinjau asli Z-Image (480p 9:16, subjek = karakter pertama) disimpan di `styleThumbs[id]{job,img}` dan menggantikan SVG; "Pratinjau semua" mengantre yang belum ada. Foto contoh Pexels untuk 9 gaya (`photo:{id,by,page,css}`; dipilih dari hasil pencarian web karena Pexels/Unsplash/Pixabay diblokir dari container, jadi fotonya belum pernah dilihat langsung): `GET /api/stylethumb?pid=` mengunduh `images.pexels.com/photos/<id>/pexels-photo-<id>.jpeg?...w=360&h=640&fit=crop` dari PC pengguna ke `cache/styles/<id>.jpg` (harus JPEG; gagal = jeda 10 menit); UI menimpa SVG dengan foto, `phFail` mencoba URL langsung lalu kembali ke SVG. Anime/buku cerita/pixel/flat tetap SVG (stok foto Pexels untuk itu kebanyakan cosplay/figur berhak cipta). Shutterstock tidak boleh dipakai (berbayar). Hindari tiruan tokoh berhak cipta di SVG (kartun klasik pakai topi bowler, bukan telinga bulat).
- `llm.py` — penulis lewat **Ollama** lokal gratis (`ollama_url`, `llm_model`, saran `qwen3:8b`): `ideas`, `storyline`, `script` (+ `fit_durations`), `breakdown` (look, karakter, lokasi, properti, isi tiap scene; deskripsi English). **Dialog/VO**: di `S_SCRIPT` kolom `dialog`/`onscreen_text` WAJIB (structured output Ollama hampir selalu melewati kolom opsional; dulu penyebab dialog kosong); `voice` proyek (mix|dialog|vo|none) → `VOICE` + `_voice_rules` (format `Nama: ucapan` / `VO: narasi`, maks ~2.3 kata/detik); tugas `dialog` menulis ulang dialog saja. UI: pilihan Suara di tahap 2, penghitung kata per scene, `speech()` memasukkan dialog ke prompt video bila mesin bersuara (`_studio.audio` workflow, atau Seedance model audio + Generate audio) dan `prod.speak` tidak dimatikan; subtitle dialog membuang nama pembicara. TTS/rekaman VO terpisah belum ada. `/api/chat` + `format` JSON schema, `think:false` (dibuang bila ditolak). App memanggil ComfyUI `/free` sebelum menulis bila tak ada job. Unduh model: `PULL` ditandai aktif sebelum thread jalan, error diberi petunjuk; `cek-ollama.bat` untuk diagnosis. Panggilan ke Ollama tanpa proxy sistem.
- `render.py` — Editing: ffprobe tiap klip, trim, skala+pad ke ukuran klip pertama, fps 24, audio klip atau senyap (`anullsrc`), cut (`concat`) atau crossfade (`xfade`+`acrossfade`), subtitle `drawtext textfile=` (font Yu Gothic/Meiryo untuk huruf Jepang), musik `-stream_loop -1` + `amix normalize=0` + fade out, libx264/aac.
- `updater.py` — pembaruan tanpa git: `GET api.github.com/repos/dimsumprasetya/VideoGen/commits/<update_branch>` (Accept: vnd.github.sha) dibanding `version.txt`; bila beda unduh `archive/<sha>.zip` dan salin di atas folder, kecuali `KEEP` (studio_config.json, api_key.txt, python_path.txt, version.txt, log) dan `KEEP_DIRS` (outputs, projects). `update_branch` default `claude/focused-lovelace-y9fz03` (push pembaruan ke branch ini supaya sampai ke pemilik). `python updater.py --now|--check`; `update.bat` memakainya.
- `studio.pyw` — supervisor: menyalakan ComfyUI + `app.py` tanpa jendela, restart otomatis, jendela `--app` Edge/Chrome, rotasi `studio.log` (>5 MB). `comfy_alive` = cek port TCP (bukan HTTP: ComfyUI yang sibuk lambat menjawab dan dulu dianggap mati → ComfyUI kedua dinyalakan berulang); saat start langsung, setelahnya baru dinyalakan bila 3x berturut-turut mati (15 dtk) dan proses milik supervisor sudah berhenti. **Auto-update**: 60 dtk setelah start lalu tiap `update_check_hours` (3) bila `/api/busy` false; bila `studio.pyw/updater.py/comfy_detect.py` berubah supervisor menjalankan dirinya lagi (`--no-window --adopt-comfy <pid>`, ComfyUI tidak dimatikan), selain itu hanya `app.py` direstart. UI menampilkan banner "Muat ulang" saat versi berubah. Satu instance lewat lock socket di `app_port + 1`.
- `install.ps1` — installer sekali jalan (`irm https://raw.githubusercontent.com/dimsumprasetya/VideoGen/claude/focused-lovelace-y9fz03/install.ps1 | iex`, atau `install.bat`): pasang ke `C:\AI\SeedanceStudio` (`$env:SEEDANCE_DIR`), hentikan & pindahkan data pemasangan lama (target shortcut Desktop), catat `version.txt`, cari Python (sistem / `python_embeded` ComfyUI / winget) → `python_path.txt`, set `update_branch`, winget ffmpeg + Ollama (+ `ollama pull qwen3:8b`) bila belum ada, shortcut Desktop + Start Menu, auto-start (Startup), lalu nyalakan. Sintaks dicek dengan parser PowerShell 7; belum dijalankan di Windows sungguhan.
- `studio.vbs` — peluncur tersembunyi. `stop.bat`, `autostart-on/off.bat`, `run.bat` (console), `buat-shortcut.bat`, `cek-comfy.bat`, `cek-ollama.bat`, `findpy.bat` (python_path.txt → python sistem → python_embeded).
- PENTING saat menulis .bat dari shell container ini: kata `nul` setelah `>` bisa berubah jadi `/dev/null`; tulis .bat lewat Python dan cek `grep /dev/null *.bat`.
- API key akun Comfy (wajib untuk node API berbayar bila dipanggil lewat `/prompt` tanpa UI ComfyUI) dikirim di `extra_data.api_key_comfy_org`; disimpan di `api_key.txt` (gitignored) lewat UI, atau env `COMFY_API_KEY`.
- Model/aspek/resolusi Seedance dibaca dari `/object_info/ByteDanceTextToVideoNode`; input yang tidak dimiliki node disaring sebelum dikirim.
- `studio_config.json` — `comfy_cmd`, `comfy_cwd`, `comfy_ports` (8188 ComfyUI biasa, 8000 ComfyUI Desktop), `app_port`, `update_branch`, `auto_update`, `update_check_hours`, `ollama_url`, `llm_model`, dll.
- `comfy_detect.py` — deteksi/resolusi perintah menyalakan ComfyUI (Desktop .exe, folder manual, paket portable). Pilihan dari panel ⚙ disimpan ke `studio_config.json`; supervisor membacanya ulang tiap 5 dtk.
- ComfyUI pemilik: portable di `C:\AI\ComfyUI_windows_portable` (python_embeded, port 8188, tanpa autentikasi), juga dipakai Luminar Studio (`C:\AI\relight-studio`, backend :8001). Start: `python_embeded\python.exe -s ComfyUI\main.py --listen 127.0.0.1 --port 8188 --disable-auto-launch` dengan cwd folder portable; sudah diisi di `studio_config.json`. VRAM 8 GB.
- Menumpang ComfyUI yang sudah jalan: `comfy_url()` mencari port dari proses ComfyUI (PowerShell) bila 8188/8000 mati; panel setup juga menerima port.
- `workflows/` — workflow custom format **API**. Placeholder `{{PROMPT}} {{SEED}} {{DURATION}} {{ASPECT}} {{RESOLUTION}} {{WIDTH}} {{HEIGHT}} {{FRAMES}}`. Kunci `_studio` (dibuang sebelum `/prompt`): `kind` (video|image|audio → menentukan di tahap mana workflow muncul), label, note, max_short, max_duration, fps, frame_step, frame_offset, timeout, models[{folder,file,gb,url}] (dicek lewat `GET /models/<folder>`, tombol unduh ke folder dari `GET /internal/folder_paths`). Hasil video/audio/gambar dikenali dari ekstensi.
- Workflow bawaan (lokal, gratis, diturunkan manual, **belum diuji dengan ComfyUI asli**): `minimax-h3-lokal.json` (video+audio, ~40 GB model, sangat lambat di 8 GB), `z-image-turbo-gambar.json` (gambar referensi/sketsa), `ace-step-musik.json` (musik instrumental, `TextEncodeAceStepAudio`/`EmptyAceStepLatentAudio`/`SaveAudio`, checkpoint `ace_step_v1_3.5b`).
- Uji tanpa Windows: ComfyUI palsu (port 8188: `/system_stats`, `/models/*`, `/prompt`, `/history/*`, `/view` mengembalikan file mp4/png/flac nyata), Ollama palsu (port 11434: `/api/tags`, `/api/version`, `/api/pull`, `/api/chat` per schema), lalu Playwright (`npm root -g`/playwright, Chromium `/opt/pw-browsers/chromium-1194`; Chromium ini tidak memutar H.264, thumbnail hitam itu normal). PowerShell 7 untuk cek sintaks bisa diunduh dari rilis GitHub PowerShell.

## Catatan penting
- Node bawaan: `ByteDanceTextToVideoNode`, `ByteDanceImageToVideoNode`, `SaveVideo`. Model: seedance-1-0-pro-fast-251015, seedance-1-5-pro-251215 (durasi min 4 dtk, bisa audio), seedance-1-0-pro-250528, seedance-1-0-lite (t2v/i2v). Seedance 2.0 (`ByteDance2TextToVideoNode`, input dinamis) BELUM didukung workflow bawaan; lewat workflow custom. Belum diuji dengan ComfyUI + Seedance asli, jadi nama input node 2.0 perlu diverifikasi lewat `/object_info/ByteDance2TextToVideoNode`.
- Hanya pustaka standar Python. Jangan tambah dependensi tanpa alasan kuat.
- Target: Windows 10/11, Python di PATH, ffmpeg di PATH untuk fitur gabung.

## Ide lanjutan
SFX (Stable Audio Open, model gated) & VO/TTS di tahap 5, image-to-video memakai gambar referensi karakter sebagai frame pertama, Seedance 2.0 sebagai workflow bawaan, upload langsung ke YouTube, `tailscale serve` (HTTPS) untuk akses HP.
