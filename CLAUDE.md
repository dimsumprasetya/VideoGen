# Seedance Shorts Studio

Web UI lokal (Python stdlib saja, tanpa dependensi) untuk membuat klip YouTube Shorts lewat ComfyUI + node API Seedance (ByteDance). Seedance berjalan di cloud lewat API node ComfyUI (butuh login akun Comfy + kredit), bukan di GPU lokal.

## File
- `app.py` — server HTTP (port 7860, hanya 127.0.0.1). UI di `ui.html` (dibaca tiap request, `Cache-Control: no-store`). Proteksi: Host harus 127.0.0.1/localhost (anti DNS-rebinding) dan setiap POST wajib header `X-Studio: 1` (anti CSRF; tanpa ini situs lain bisa memicu generate berbayar/hapus file/ganti `comfy_cmd`). Job ComfyUI masuk antrean `WORK` dan dikerjakan **satu per satu** oleh thread `worker` (timeout dihitung saat job mulai). `GET /api/busy` dipakai supervisor sebelum update. Upload: `POST /api/upload?name=` (body mentah). Render: `POST /api/render` → `render.py` di thread, status lewat `JOBS`.
- `ui.html` — UI satu halaman, alur **linear** 5 tahap: 1 Ide → 2 Script → 3 Breakdown → 4 Production → 5 Editing & Sound. Tombol "Lanjut" di tiap tahap menjalankan pekerjaan tahap berikutnya bila belum ada (storyline → script → breakdown). Pengaturan (ComfyUI, model workflow, Ollama, API key, versi/update) di panel ⚙. Semua data di `projects/<nama>.json` (v2): `dev, story, target, maxScene, scenes[] (duration, location, time, action, dialog, onscreen_text, visual, chars[], loc, props[], shot, cam, sketch{job,img}, prompt (override), takes[{job,file}], take, use, tin, tout, sub), look{style,camera,lighting,palette}, chars[{name,look,wardrobe,makeup,job,img}], locs[], props[], bd, imgwf, prod{engine,model,aspect,resolution,audio}, edit{tr,fade,ca,cv,sub,music,audios,mv,mwf,mp,mjob,rjob,final}`. `migrate()` mengubah proyek lama (panels/style). Job dihubungkan ke item lewat id (sisi klien, `poll()`); prompt video = `compose()` (style + shot/kamera + visual + karakter (fisik, wardrobe, make-up) + lokasi + properti + lighting/palet, "no on-screen text" karena subtitle ditambahkan di Editing).
- `llm.py` — penulis lewat **Ollama** lokal gratis (`ollama_url`, `llm_model`, saran `qwen3:8b`): `ideas`, `storyline`, `script` (+ `fit_durations`), `breakdown` (look, karakter, lokasi, properti, isi tiap scene; deskripsi English). `/api/chat` + `format` JSON schema, `think:false` (dibuang bila ditolak). App memanggil ComfyUI `/free` sebelum menulis bila tak ada job. Unduh model: `PULL` ditandai aktif sebelum thread jalan, error diberi petunjuk; `cek-ollama.bat` untuk diagnosis. Panggilan ke Ollama tanpa proxy sistem.
- `render.py` — Editing: ffprobe tiap klip, trim, skala+pad ke ukuran klip pertama, fps 24, audio klip atau senyap (`anullsrc`), cut (`concat`) atau crossfade (`xfade`+`acrossfade`), subtitle `drawtext textfile=` (font Yu Gothic/Meiryo untuk huruf Jepang), musik `-stream_loop -1` + `amix normalize=0` + fade out, libx264/aac.
- `updater.py` — pembaruan tanpa git: `GET api.github.com/repos/dimsumprasetya/VideoGen/commits/<update_branch>` (Accept: vnd.github.sha) dibanding `version.txt`; bila beda unduh `archive/<sha>.zip` dan salin di atas folder, kecuali `KEEP` (studio_config.json, api_key.txt, python_path.txt, version.txt, log) dan `KEEP_DIRS` (outputs, projects). `update_branch` default `claude/focused-lovelace-y9fz03` (push pembaruan ke branch ini supaya sampai ke pemilik). `python updater.py --now|--check`; `update.bat` memakainya.
- `studio.pyw` — supervisor: menyalakan ComfyUI + `app.py` tanpa jendela, restart otomatis, jendela `--app` Edge/Chrome, rotasi `studio.log` (>5 MB). **Auto-update**: 60 dtk setelah start lalu tiap `update_check_hours` (3) bila `/api/busy` false; bila `studio.pyw/updater.py/comfy_detect.py` berubah supervisor menjalankan dirinya lagi (`--no-window --adopt-comfy <pid>`, ComfyUI tidak dimatikan), selain itu hanya `app.py` direstart. UI menampilkan banner "Muat ulang" saat versi berubah. Satu instance lewat lock socket di `app_port + 1`.
- `install.ps1` — installer sekali jalan (`irm https://raw.githubusercontent.com/dimsumprasetya/VideoGen/claude/focused-lovelace-y9fz03/install.ps1 | iex`, atau `install.bat`): pasang ke `C:\AI\SeedanceStudio` (`$env:SEEDANCE_DIR`), hentikan & pindahkan data pemasangan lama (target shortcut Desktop), catat `version.txt`, cari Python (sistem / `python_embeded` ComfyUI / winget) → `python_path.txt`, set `update_branch`, winget ffmpeg + Ollama (+ `ollama pull qwen3:8b`) bila belum ada, shortcut Desktop + Start Menu, auto-start (Startup), lalu nyalakan. Sintaks dicek dengan parser PowerShell 7; belum dijalankan di Windows sungguhan.
- `studio.vbs` — peluncur tersembunyi. `stop.bat`, `autostart-on/off.bat`, `run.bat` (console), `buat-shortcut.bat`, `cek-comfy.bat`, `cek-ollama.bat`, `findpy.bat` (python_path.txt → python sistem → python_embeded).
- PENTING saat menulis .bat dari shell container ini: kata `nul` setelah `>` bisa berubah jadi `/dev/null`; tulis .bat lewat Python dan cek `grep /dev/null *.bat`.
- API key akun Comfy (wajib untuk node API berbayar bila dipanggil lewat `/prompt` tanpa UI ComfyUI) dikirim di `extra_data.api_key_comfy_org`; disimpan di `api_key.txt` (gitignored) lewat UI, atau env `COMFY_API_KEY`.
- Model/aspek/resolusi Seedance dibaca dari `/object_info/ByteDanceTextToVideoNode`; input yang tidak dimiliki node disaring sebelum dikirim.
- `studio_config.json` — `comfy_cmd`, `comfy_cwd`, `comfy_ports` (8188 ComfyUI biasa, 8000 ComfyUI Desktop), `app_port`, `update_branch`, `auto_update`, `update_check_hours`, `ollama_url`, `llm_model`, dll.
- `comfy_detect.py` — deteksi/resolusi perintah menyalakan ComfyUI (Desktop .exe, folder manual, paket portable). Pilihan dari panel ⚙ disimpan ke `studio_config.json`; supervisor membacanya ulang tiap 5 dtk.
- ComfyUI pemilik: portable di `C:\AI\ComfyUI_windows_portable` (python_embeded, port 8188, tanpa autentikasi), juga dipakai Luminar Studio (`C:\AI\relight-studio`, backend :8001). Start: `python_embeded\python.exe -s ComfyUI\main.py --listen 127.0.0.1 --port 8188 --disable-auto-launch` dengan cwd folder portable; sudah diisi di `studio_config.json`. VRAM 8 GB.
- Menumpang ComfyUI yang sudah jalan: `comfy_url()` mencari port dari proses ComfyUI (PowerShell) bila 8188/8000 mati; panel setup juga menerima port.
- `workflows/` — workflow custom format **API**. Placeholder `{{PROMPT}} {{SEED}} {{DURATION}} {{ASPECT}} {{RESOLUTION}} {{WIDTH}} {{HEIGHT}} {{FRAMES}}`. Kunci `_studio` (dibuang sebelum `/prompt`): `kind` (video|image|audio → menentukan di tahap mana workflow muncul), label, note, max_short, max_duration, fps, frame_step, frame_offset, timeout, models[{folder,file,gb,url}] (dicek lewat `GET /models/<folder>`, tombol unduh ke folder dari `GET /internal/folder_paths`). Hasil video/audio/gambar dikenali dari ekstensi.
- Workflow bawaan (lokal, gratis, diturunkan manual, **belum diuji dengan ComfyUI asli**): `minimax-h3-lokal.json` (video+audio, ~40 GB model, sangat lambat di 8 GB), `z-image-turbo-gambar.json` (gambar referensi/sketsa), `ace-step-musik.json` (musik instrumental, `TextEncodeAceStepAudio`/`EmptyAceStepLatentAudio`/`SaveAudio`, checkpoint `ace_step_v1_3.5b`).
- Uji tanpa Windows: ComfyUI palsu (port 8188: `/system_stats`, `/models/*`, `/prompt`, `/history/*`, `/view` mengembalikan file mp4/png/flac nyata), Ollama palsu (port 11434: `/api/tags`, `/api/version`, `/api/pull`, `/api/chat` per schema), lalu Playwright (`npm root -g`/playwright, Chromium `/opt/pw-browsers/chromium-1194`; Chromium ini tidak memutar H.264, thumbnail hitam itu normal). PowerShell 7 untuk cek sintaks bisa diunduh dari rilis GitHub PowerShell.

## Catatan penting
- Node bawaan: `ByteDanceTextToVideoNode`, `ByteDanceImageToVideoNode`, `SaveVideo`. Model: seedance-1-0-pro-fast-251015, seedance-1-5-pro-251215 (durasi min 4 dtk, bisa audio), seedance-1-0-pro-250528, seedance-1-0-lite (t2v/i2v). Seedance 2.0 (`ByteDance2TextToVideoNode`, input dinamis) BELUM didukung workflow bawaan; lewat workflow custom. Belum diuji dengan ComfyUI + Seedance asli, jadi nama input node 2.0 perlu diverifikasi lewat `/object_info/ByteDance2TextToVideoNode`.
- Hanya pustaka standar Python. Jangan tambah dependensi tanpa alasan kuat.
- Target: Windows 10/11, Python di PATH, ffmpeg di PATH untuk fitur gabung.

## Ide lanjutan
SFX (Stable Audio Open, model gated) & VO/TTS di tahap 5, image-to-video memakai gambar referensi karakter sebagai frame pertama, Seedance 2.0 sebagai workflow bawaan, upload langsung ke YouTube.
